# DecodeLabs Responsive Dashboard - Task 1

This repository contains the Week 1 submission for the DecodeLabs remote full-stack development internship.

## Features Implemented:
* **Semantic HTML5 Layout:** Structured macro-elements for optimized accessibility.
* **Mobile-First CSS Grid:** Fluid and responsive design that scales seamlessly from mobile viewports up to desktop displays.
* **Vanilla JavaScript Interactivity:** Real-time client-side features including a dynamic greeting system, a live digital clock, and a responsive sidebar navigation toggle.
